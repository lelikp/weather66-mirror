# weather66-mirror

Пересылает все посты Telegram-канала @weather66 в ВКонтакте (и в Макс, когда он будет настроен).
Бот-администратор канала забирает новые посты через `getUpdates`; прочитанное подтверждается только после успешной
публикации. Репозиторий публичный: токены лежат в Secrets, тексты постов в лог не пишутся.

## Secrets (Settings → Secrets and variables → Actions)
| Имя | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота (администратор канала) |
| `TELEGRAM_CHANNEL_ID` | `@weather66` или числовой id канала |
| `VK_TOKEN` | ключ доступа сообщества (права: стена, фотографии, управление) |
| `VK_GROUP_ID` | числовой id сообщества (допустимо короткое имя `weather66`) |
| `VK_USER_TOKEN` | необязательно: токен администратора сообщества (права `photos`, `wall`), только для загрузки картинок |
| `MAX_TOKEN`, `MAX_CHAT_ID` | позже, для Макс |

## Первый запуск
1. Actions → tg-mirror → Run workflow, **check = true**: проверка бота, webhook, токена ВК и прав. Ничего не публикуется.
2. Run workflow, **skip_backlog = true**: отмечает накопившиеся за сутки посты прочитанными, не пересылая их.
3. Добавьте задание на cron-job.org (`POST .../actions/workflows/mirror.yml/dispatches`, тело `{"ref":"main"}`) каждые 15–30 минут.

## Картинки в ВК
Ключ сообщества не может загружать фото на стену (ВК отвечает ошибкой 27 «method is unavailable with group auth»);
текст он публикует нормально. Поэтому картинки грузятся по цепочке: фото токеном пользователя (если задан
`VK_USER_TOKEN`) → фото ключом сообщества → картинка как документ → без картинки (в пост добавляется ссылка на
оригинал в Telegram). Какие пути доступны вашему ключу, показывает запуск с `check = true`.

## Что переносится
Текст (разметка снимается, ссылки превращаются в «слово (адрес)»), фото и альбомы (альбом уходит одним постом после
паузы 30 с). Видео, файлы, опросы не переносятся: в пост добавляется ссылка на оригинал. Правки и удаление постов в
Telegram боту не видны. При сбое пост остаётся в очереди (Telegram хранит 24 часа) и уходит при следующем запуске;
если пост дошёл не во все сети, job станет красным, повторной отправки не будет, чтобы не создавать дубли.
